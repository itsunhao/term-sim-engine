# TermSim Engine —— 终端风格模拟经营游戏引擎

Spring Boot 3.3.5 + Thymeleaf 实现的模拟经营游戏引擎：**引擎 + JSON 游戏文件**，开箱自带「街角小卖部」游戏。

## 快速开始



```
\# 需要 JDK 17+ 与 Maven

mvn spring-boot:run            # 或：mvn -DskipTests package && java -jar target/term-sim-engine.jar

\# 打开浏览器

open http://localhost:8899/
```

## 功能速览



* 终端风格界面（CRT 扫描线、荧光绿、命令行、启动动画）；**Three.js 3D 终端背景（v1.12.0）**——粒子星云 / 网格地平线 / 漂浮线框几何体 / 光晕，深绿发光风，垫在 UI 之下不遮挡交互，面板半透明透光，THREE 加载失败自动降级

* 实时时间流：现实 1 秒 = 游戏 1 分钟，HH:MM 时钟显示，支持暂停 / 继续 / 打烊快进 / 时间倍速（0.5×~5×）

* 四季 × 天气 × 时段影响客流与商品需求（早 / 午 / 晚）

* 进货 / 定价 / 贷款（按游戏日实时计息）/ 装修解锁新品类 / 随机事件

* 6 位 NPC 街坊：好感度变化 + 评价台词 + **主动社交**（闲聊/送礼/请客，好感 50+ 带客、80+ 宣传）

* 玩法扩展：每日晨报（随机增益/预警）、主动限时促销（广告换限时客流，可突破平日上限）、爆款热卖（随机商品限时需求翻倍）、成就系统（13 个里程碑，终端庆祝 + 成就页）

* **贸易策略**：小卖部可配置批发（批量卖货给批发商快速回笼现金）；饭馆可配置外卖平台（开通后每日自动接单、占厨房产能、评价影响声誉）

* **雇佣系统**：按月薪雇佣员工（自动进货/揽客/采购让价/外卖加成/安保保洁），涨薪提效率、降薪省成本但可能离职，发薪日现金不足会欠薪跑人

* **实时终端日志**：每一笔成交、每一次随机事件（如小偷光顾）都会实时滚动到终端，经营过程一目了然

* **银行存取款**：随时存入/取出，年化利率按游戏日复利计息；现金放店里会被小偷偷，存银行更稳（净资产计入存款）

* **NPC 委托订单**：街坊清晨可能下单（指定商品 N 件限时交货），到期库存足够 → 交货拿溢价报酬 + 好感，不足 → 声誉受损

* **幸运彩票**：每日一张，次日清晨开奖，小额成本博取随机奖金

* 保质期过期损耗、声誉漂移、净资产胜负判定

* **地图地产**：4 处地段客流量与房价不同，可申请房屋贷款购买新地产、迁移店铺（库存自动随店走），每月等额本息还款
* **个人形象（v1.7.0）**：装扮（帽/上衣/裤/表/鞋，可选街坊工坊、小林制衣、奥罗拉、菲尼克斯、时代表行等品牌）、购置车/住宅资产，穿戴与资产共同提升「个人声望」；声望高 → 客单价溢价（上限 +15%）、街坊带客/宣传更勤、**NPC 主动上门互动**（打招呼→送礼→带客→合影→豪礼），界面新增「形象」标签页与 wear/buyitem/buyasset/wardrobe 命令
* **实时补货 / 理财 / 刮刮乐（v1.8.0+）**：可雇佣「实时补货员」——货架空缺即补（v1.8.3 规则：现金满足补 10 件、现金不足补最大可买，按刷新频率检查，先补后扣，原子扣款无并发无多扣）；银行新增理财产品（定期锁定、到期自动兑付本金+利息、可提前赎回只退本金）；幸运彩票新增刮刮乐（即买即刮、上不封顶）；顶栏新增 ⚙ 设置（倍速/暂停收拢于此）、💾 随时存档、🏠 返回游戏选择
* **分店系统（v1.9.0）**：可开设分店（费用逐店递增、需声望门槛），界面顶部「店铺切换条」一键切换每家店；**新店与老店的库存 / 定价 / 装修 / 雇员 / 选址客流完全独立**；现金、存款、贷款、理财为**全局唯一账户**（开分店、进货、发薪、销售均精确入账）；开店选址自动排除已占用地段，地图房屋贷款同样支持迁移当前店
* **供应链（v1.10.0）**：「恒昌商贸行 / 鲜味源供应链」——进货实付金额自动累计**合作值**，等级从普通客户→稳定客户→金牌客户→战略伙伴逐级解锁进货折扣（最高 88 折）、**赊账进货**（账期 30 游戏天，到期自动扣款，逾期罚息 10% + 顺延 + 合作值 -200）与**独家高毛利商品**（如精酿气泡水、秘制烧鹅）；「贸易」页顶部新增供应链卡，终端命令 `supply` / `buy_credit <商品> <数量>`
* **口碑评级（v1.10.0）**：每日按 **价格分（定价偏离 30 分）＋ 新鲜分（过期损耗 25 分）＋ 服务分（雇员/装修/促销 45 分，欠薪与负面事件扣分）** 结算满意度（0~100）；满意度实时影响客流（±20% 回头客）与客单价（±10%），评级 0 级再客流 -5%；每 30 游戏天按月度均值结算**口碑评级**：街坊小铺 → 口碑小店 → 邻里名店 → 街区标杆（85/70/55 分界线，2 级客单价 +4%、3 级 +8%），状态栏常驻评级徽章、报表页展示近 30 天满意度走势
* **街区竞争（v1.10.0）**：声誉达标后竞争对手（老王便利店、隔壁面馆…）逐批登场抢客流（被抢比例 = 对手热度×强度 ÷(同 + 你的声誉×2) ×0.55，封顶 40%），热度每日自然增长、登场前 3 天适应期；玩家可 **⚔ 价格战**（180 分钟定价 -10%、客流 +25%，对手每日 -6）/ **📣 营销战**（花钱广告，对手热度 -8、客流 +10%、满意度 +2）/ **🗣 口碑攻势**（需一位街坊好感 ≥60，对手 -5、好感 +3），行动冷却 720 分钟共用；把对手热度压到 ≤15 连续 3 天可将其**打到歇业**（成就「街区称霸」），歇业 90 天后可能卷土重来；「竞争」标签页实时展示对手热度条与行动按钮，命令 `compete` / `price_war` / `ad_war` / `charm_off`
* **节日庆典（v1.11.0）**：四季各一场应季节日（小卖部：新春庙会/夏日冰爽节/金秋丰收节/暖冬年货节；饭馆：美食节/夏夜大排档/丰收宴/年夜饭专场），开幕前 1 天进入筹备窗口、节日期间也可追加**筹备金**（上限每场 `setup_cap`）；筹备度直接换算节日**客流加成**（满额 +30%）、客单价 +10%，节日**特定商品需求倍率**暴涨；节日期间每日随机小事件（巡游/游客/白忙一场…）；闭幕自动结算战报：**筹备金回报（筹备 × 回报倍率）+ 筹备满额的节日营业额 10% 抽成**，现金入账并记入「节日历史」；状态栏节日徽章、报表页节日卡（进行中/筹备中/下一节日/上次战报），命令 `festival` / `festival_setup <金额>`
* **员工培养晋升（v1.11.0）**：雇员每天（及每次自动补货动作）获得经验，累计升级 Lv.2/Lv.3（每级效率 +5%，效率上限提至 1.90）；**忠诚度**系统——发薪日 +5、涨薪 +8、发红包 +10（节日期间 ×2，每次 200 元）、欠薪 -15、降薪 -10、每日缓慢回升至 60 封顶，忠诚 <20 离职风险大增；满级 + 忠诚 ≥60 可花**月薪 ×3 晋升骨干**（效率 +10%、全员共享店长光环，忠诚 -10），晋升后从角色**技能池**选 1 项永久技能（闪电补货/砍价大师/流量密码/秘制配方/好评引导…，直接叠加到实时补货、进货让价、客流、客单价、外卖单量、事件抑制等既有系统）；雇员页新增经验条/忠诚/技能显示与晋升/红包/选技能交互，命令 `promote` / `pick_skill` / `redpacket`

* 所有列表（货架 / 定价 / 装修 / 贷款 / 报表 / 贸易 / 雇员 / 街坊 / 成就）分页展示，页面不臃肿

* JSON 游戏文件安装即玩；存档自动落盘、多存档管理

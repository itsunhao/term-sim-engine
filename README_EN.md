# 🏪 TermSim Engine · Terminal Simulation Game Engine

> 🤖 **AI-Generated Project · 0 Lines of Hand-Written Code**
>
> The entire engine code, gameplay logic, Thymeleaf templates, frontend styles, and both JSON game files were generated by an AI LLM. The author's role was defining requirements, planning gameplay, iterating version by version, writing tests and verifying.

A terminal-style simulation game engine built with **Spring Boot 3.3.5 + Thymeleaf**. Core philosophy: **engine + game file (JSON) separation** — swap one JSON and you get a completely different game.

- **Engine** (Java): generic simulation framework — time/seasons/weather, customer flow, NPC social, loans, random events, save system
- **Game file** (JSON): defines actual gameplay — convenience store, restaurant, bubble tea shop... any scenario is "install and play" via one JSON
- **UI**: classic CRT terminal aesthetic — green text, scanlines, blinking cursor, boot animation, command-line input

Ships with two complete games: **Corner Convenience Store** and **Corner Street Restaurant**.

## ✨ Features (12 versions, v1.0 → v1.12)

| Module | Details |
|---|---|
| **Time system** | Real 1s = game 1min, HH:MM clock, pause/resume/after-hours fast-forward, speed control (0.5×~5×) |
| **Seasons × weather** | 4 seasons × weather × time-of-day affect customer flow and product demand |
| **Core simulation** | Restock / pricing / loans (daily compound interest) / renovation unlocking new categories / random events |
| **NPC social** | 6 neighbors with affinity, dialogue lines, active social (chat/gift/treat); affinity 50+ brings customers, 80+ promotes you |
| **Daily brief & promos** | Daily morning brief (random buff/warning), limited-time promotions, viral hot items, 13 achievements |
| **Trade strategies** | Convenience store: wholesale bulk selling; restaurant: food delivery platform with daily auto-orders and reviews |
| **Employee system** | Hire staff monthly (auto-restock/customer attraction/bargaining/delivery bonus/security); raises boost efficiency, cuts may cause resignation |
| **Real-time terminal log** | Every transaction, every random event (e.g. shoplifter) scrolls live in the terminal |
| **Banking** | Deposit/withdraw anytime, daily compound interest; cash in store gets stolen, bank is safer |
| **NPC commission orders** | Neighbors place morning orders (N items by deadline); deliver for premium payout + affinity, miss and reputation drops |
| **Lottery** | Daily ticket, next-morning draw; small cost for random jackpot |
| **Map real estate** | 4 locations with different customer flow and prices; mortgage loans, shop migration, monthly amortization |
| **Personal style (v1.7)** | 5-part outfit (hat/top/pants/watch/shoes), car/property assets, personal reputation drives NPC visits and 15% price premium |
| **Auto-restock & wealth (v1.8+)** | Auto-restocker (fills shelves when empty), bank wealth management (fixed-term), scratch cards, settings panel, quick save |
| **Branch system (v1.9)** | Open independent branches (escalating costs, reputation requirement); inventory/pricing/staff/location fully per-branch; cash/bank/loans are global |
| **Supply chain (v1.10)** | Partnership tiers (regular → stable → gold → strategic), up to 12% discount, 30-day credit purchases, exclusive high-margin products |
| **Reputation rating (v1.10)** | Daily satisfaction score (price 30 + freshness 25 + service 45), 0~100; monthly rating from corner shop to neighborhood benchmark; real-time impact on customer flow ±20% and average spend ±10% |
| **Street competition (v1.10)** | Rivals appear to steal customers (capped 40%); counter with price war / marketing campaign / reputation offensive (720-min cooldown); driving rivals out of business earns "Street Dominator" achievement |
| **Festival events (v1.11)** | 4 seasonal festivals per year (spring temple fair / summer ice festival / autumn harvest festival / winter goods festival); setup funds boost customer flow up to +30%, closing day settlement with setup ROI + 10% revenue cut |
| **Staff training & promotion (v1.11)** | Employees gain XP daily (Lv.2/Lv.3, +5% efficiency each), loyalty system (payday +5, raise +8, red packet +10, missed pay -15); max level + loyalty ≥60 can promote to "elite" (3× monthly salary, +10% efficiency + store-wide aura), then pick 1 permanent skill |
| **3D background (v1.12)** | Three.js full-page 3D terminal background — dual-layer green particle nebula + wireframe grid horizon + floating wireframe geometries (octahedron/torus knot/icosahedron) + radial glow; semi-transparent frosted glass UI panels; auto-fallback if WebGL unavailable |
| **Quality** | 62 JUnit 5 engine tests, pure JSON storage, no database dependency |

## 🚀 Quick Start

```bash
# Requires JDK 17+ and Maven
git clone https://github.com/itsunhao/term-sim-engine.git
cd term-sim-engine
mvn spring-boot:run
# Or: mvn -DskipTests package && java -jar target/term-sim-engine.jar
# Open http://localhost:8899/ in browser
```

## 🤖 About AI Generation

This engine was **not hand-coded** — it was entirely AI-generated:

- **0 hand-written code**: All Java engine code, gameplay logic, Thymeleaf templates, frontend styles, and both JSON game files were generated by an AI LLM
- **Author's work**: Define requirements ("I want a terminal-style convenience store management game"), plan gameplay, iterate version by version, write 62 test cases and verify each release
- **12 versions** (v1.0 → v1.12) produced a complete system: branch management, supply chain, reputation ratings, street competition, seasonal festivals, staff promotion, and Three.js 3D background

The takeaway: **the boundary of AI programming is much wider than you think** — as long as requirements are broken down precisely and iteration is tight, a "zero hand-written code" project can grow quite large.

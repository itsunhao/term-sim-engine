## 📖 About

**TermSim Engine** is a terminal-style simulation game engine built with **Spring Boot 3.3.5 + Thymeleaf**. Core idea: **engine + game file (JSON) separation** — swap one JSON file and you get a completely different game.

- **Engine** (Java): provides the generic simulation framework — time/seasons/weather, customer flow, NPC social, loans, random events, save system;
- **Game file** (JSON): defines the actual gameplay — convenience store, restaurant, bubble tea shop... any scenario is "install and play" via one JSON;
- **UI**: classic CRT terminal aesthetic — green text, scanlines, blinking cursor, boot animation.

Ships with two complete games: **Corner Convenience Store** and **Corner Street Restaurant**.

## ✨ Features (12 iterations)

| Module | Details |
|---|---|
| Time system | Real 1s = game 1min, pause/speed control (0.5×~5×), seasons × weather × time-of-day |
| NPC social | 6 neighbors, affinity + dialogue + active social (chat/gift/treat), commission orders |
| Business strategy | Wholesale trading, food delivery platform, employee system, banking, supply chain discounts |
| Real estate | 4 locations with loans, shop migration, multiple independent branches |
| Competition & events | Street rivals (price wars/marketing), seasonal festivals, reputation rating |
| Staff growth | XP, loyalty, promotion to骨干 (elite), permanent skills |
| 3D background | Three.js particle nebula + wireframe grid, offline fallback |
| Quality | 62 JUnit 5 tests, pure JSON storage, no database |

## 🚀 Quick Start

```bash
# Requires JDK 17+ and Maven
git clone https://github.com/itsunhao/term-sim-engine.git
cd term-sim-engine
mvn spring-boot:run
# Open http://localhost:8899/ in browser
```

## 🤖 About AI Generation

> **0 hand-written code**: All Java engine code, gameplay logic, Thymeleaf templates, frontend styles, and both JSON game files were generated by an AI LLM.
>
> **Author's role**: define requirements ("I want a terminal-style convenience store game"), plan gameplay, iterate version by version, write tests and verify.
>
> **12 versions** (v1.0 → v1.12) produced a complete system with branches, supply chain, reputation, street competition, festivals, and staff promotion.
